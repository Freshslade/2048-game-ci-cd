# AWS CI/CD 2048 Game Deployment

This project demonstrates how I built and deployed the classic **2048 web game** using a complete AWS CI/CD pipeline.  
It was inspired by *Tech with Lucy’s* “Advanced AWS Projects” tutorial, but I recreated every step myself — debugging, troubleshooting, and learning hands-on through the process.  

I also used Google’s **Gemini** to help me debug and understand specific AWS errors (like region mismatches, IAM role issues, and ECR authentication problems).  
That experience taught me not just *what* to fix, but *why* things broke — building real understanding of Docker, ECS, IAM, and networking fundamentals.
